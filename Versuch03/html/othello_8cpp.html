Ermoeglicht einen menschlichen Zug.

Die Funktion erlaubt es einem menschlichen Spieler, einen Zug auf dem Spielfeld durchzufuehren. Sie ueberprueft, ob der eingegebene Zug gueltig ist, und fuehrt ihn aus.

◆ moeglicheZuege()

int moeglicheZuege ( const int spielfeld[GROESSE_Y][GROESSE_X],
const int aktuellerSpieler )

Zaehlt alle moeglichen Zuege eines Spielers.

Die Funktion durchsucht das gesamte Spielfeld und prueft fuer jede Position, ob dort ein gueltiger Zug fuer den aktuellen Spieler moeglich ist. Fuer jede gueltige Position wird der Zaehler erhoeht.

Parameters
spielfeldDas aktuelle Spielfeld.
aktuellerSpielerDer Spieler, fuer den die moeglichen Zuege bestimmt werden.
Returns
Anzahl der moeglichen Zuege des Spielers.
