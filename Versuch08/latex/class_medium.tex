\doxysubsection{Detailed Description}
Basisklasse fuer saemtliche Medien. 

Diese Klasse stellt eine Basisklasse fuer Objekte dar, die Medien beschreiben. Von dieser Klasse werden alle anderen Medien, wie z.\+B. \doxylink{class_buch}{Buch} oder \doxylink{class_d_v_d}{DVD}, abgeleitet.
